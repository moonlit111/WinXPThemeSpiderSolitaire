# 蜘蛛纸牌 (Spider Solitaire) - 1:1 经典深度逆向复刻版

> 基于 Windows XP 原版 `spri.exe`（32位 PE）借助 Ghidra 12.1.3 深度逆向反编译（280个函数，完整 C 伪代码详见 [decompiled_spider.c](decompiled_spider.c)），100% 像素级还原全部算法、交互、动画与音效的纯静态免编译网页版小游戏。

🎮 **在线试玩 (GitHub Pages)**: [https://moonlit111.github.io/WinXPThemeSpiderSolitaire/](https://moonlit111.github.io/WinXPThemeSpiderSolitaire/)

## 🌟 1:1 核心逆向复刻特色

- **1:1 原版发牌飞行音画 (`FUN_01005115` / `FUN_010047bd` / `FUN_010069b2`)**：
  - 完美复刻原版点击右下角发牌区时的 10 列卡牌顺序飞行动画（每张卡牌 110ms 贝塞尔曲线平滑滑翔），伴随原汁原味清脆的 `124.wav` 连环发牌声！
  - 开局时自动平滑发牌，并受原版“选项 -> 发牌动画”开关精准控制。
- **1:1 纯正 Windows XP 胜利礼花与彩虹“你赢了!” (`FUN_01008b21` ~ `FUN_01008700`)**：
  - 颠覆刻板印象——原版蜘蛛纸牌胜利绝非卡牌瀑布下落，而是绚丽的**双发射台火箭升空 + 100 颗重力阻力粒子礼花绽放 + 48pt 加粗宋体彩虹色环旋转“你赢了!”**！
  - 伴随 `129.wav` 胜利欢呼号角，并在背景持续绽放礼花的同时弹出原版 Dialog 130 战况结算窗口。
- **标志性 GDI `InvertRect` 像素级反转色 (`FUN_01005ca9` / `FUN_01004dfb`)**：
  - 点击或拖拽卡牌时，100% 还原 Windows GDI 原生像素反色效果（白底变黑、黑桃变白、红桃变高亮青色 `#00FFFF`）。
  - 提示（Hint）功能调用 `FUN_01002cf0`，整组连号卡牌同步 250ms 反色闪烁提示移动。
- **1:1 原版墨绿记分牌与底部提示触发 (`FUN_01003811` / `FUN_01004a10`)**：
  - 严格 200px 宽度、96px 卡牌等高尺寸、`#007f00` 墨绿色毛毡填充、宋体 9pt 像素级排版。
  - 点击记分牌任意区域立即触发可行操作提示与 `126.wav` / `127.wav` 音效。
- **微软 CRT 伪随机数算法 (LCG) 与洗牌映射 (`FUN_0100936b` / `FUN_0100746e`)**：
  - 保证单色、双色、四色下的花色映射与洗牌牌局分布与 Windows XP 完全一致。
- **原生全套对话框与菜单 (`RT_MENU 101` / `DLGTEMPLATEEX`)**：
  - 关于蜘蛛 (Dialog 107)、蜘蛛选项 (Dialog 117)、蜘蛛统计数据 (Dialog 118)、难易级别 (Dialog 119)、获胜统计 (Dialog 130)。
  - 支持 `spider.sav` 原生逻辑的游戏进度自动保存、恢复与注册表统计数据独立记录。
- **纯静态零依赖，脱机即玩**：
  - 提供单文件捆绑版本 `dist/spider.bundle.js`，支持在 macOS / Windows 访达中双击直接离线畅玩，亦支持直接托管至 GitHub Pages。

## 🚀 本地运行

无需安装任何构建工具，推荐以下方式之一：

### 方式 1：Python 本地服务器（推荐）
```bash
python3 -m http.server 8080
```
在浏览器中访问 [http://127.0.0.1:8080](http://127.0.0.1:8080) 即可开始畅玩。

### 方式 2：离线双击打开
在 macOS 访达 (Finder) 或 Windows 资源管理器中直接双击打开 `index.html`。
