# 蜘蛛纸牌 (Spider Solitaire) - 1:1 经典复刻版

基于 Windows XP 原版 `spri.exe` 提取的原生美术素材与音效，100% 还原经典规则的纯静态网页版小游戏。

---

## 🌟 项目特色

- **1:1 原版美术与音效**：
  - 完整提取原版 52 张扑克牌位图面（`CARD1.png` ~ `CARD52.png`）及红蓝牌背（`CARDBACK.png`）。
  - 经典墨绿毛毡台面纹理（`FELT.png`）与空位虚线卡槽。
  - 原生 6 个 WAV 音效（发牌唰唰声、落牌咔哒声、满列消牌号角声、通关胜利喝彩声等）。
- **完整游戏规则与算法**：
  - **三档难度支持**：初级（单色·黑桃）、中级（双色·黑桃与红桃）、高级（四色·全部四种花色）。
  - **严格规则判定**：仅同花色连续递减牌列允许整体拖动；有空位时严格拦截发牌；满 13 张同花色 K~A 自动收牌。
  - **撤销与提示 (Undo & Hint)**：支持 `Ctrl+Z` / `Cmd+Z` 无限回退，支持 `H` 键智能提示当前最优移动。
  - **经典通关动画**：重力弹跳卡牌瀑布残影特效。
- **专为 macOS 与现代浏览器优化**：
  - 支持 **鼠标/触控板拖拽 (Drag & Drop)** 与 **单击智能移动 (Smart Click-to-Move)** 双操作模式。
  - 牌多时自动动态压缩重叠垂直间距，防止超出视口。
- **纯静态零依赖**：
  - 无需 Node.js 编译或构建，克隆即可本地双击直接玩，极速部署至 GitHub Pages。

## 🚀 本地运行

无需安装任何依赖，推荐以下两种方式之一：

### 方式 1：Python 本地简易服务器（推荐）
在终端中进入项目目录运行：
```bash
python3 -m http.server 8080
```
然后在浏览器中访问 [http://localhost:8080](http://localhost:8080) 即可开始游玩。

### 方式 2：直接双击打开
直接在访达 (Finder) 中双击打开 `index.html`。

---

## 🌐 部署至 GitHub Pages

本项目为纯静态结构，可零配置免费托管到 GitHub Pages：

1. 将代码推送到你的 GitHub 仓库（例如 `your-username/Spider`）。
2. 在仓库页面点击 **Settings** -> 左侧导航栏 **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 选择 `Deploy from a branch`。
4. **Branch** 选择 `main`（或 `master`），目录保持 `/ (root)`，点击 **Save**。
5. 等待 1~2 分钟，即可通过 `https://your-username.github.io/Spider/` 在线游玩！

## 🎮 操作快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| **F2** | 开始新游戏 |
| **Ctrl + Z / Cmd + Z** | 撤销上一步操作 |
| **H / M** | 显示可行的高优先级移动提示 |
| **D** | 从右下角牌堆发新一轮牌（要求工作区无空列） |
| **F4** | 查看游戏统计信息（胜率、最高连胜等） |
| **单击卡牌** | 智能自动移动至最佳目标列 |
